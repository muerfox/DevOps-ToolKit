{{ icon('terminal', 15) }} Managing the cockpit

Run these from the project directory on the server. The cockpit script works for both Docker and plain-Python installs.

./cockpit status            # is it up? which mode? health check
./cockpit logs -f           # follow the server log
./cockpit update            # git pull + rebuild/reinstall + restart (DB migrates itself)
./cockpit backup            # DB snapshot + keys + kubeconfigs + .env → backups/
./cockpit restore FILE      # restore a backup (makes a safety backup first)
./cockpit reset-password U  # forgot your password?
./cockpit doctor            # check configuration and dependencies

Full reference: ./cockpit help
