Webhook (trigger from git / CI)

Trigger this pipeline (same as clicking "Run pipeline") from a push, a GitHub Actions workflow, or any CI system that can do an HTTP POST. Keep the token secret -- anyone with it can run this pipeline.

curl -X POST "{{ base_url }}/pipelines/{{ pipeline.id }}/trigger" \
  -H "X-Webhook-Token: {{ pipeline.webhook_token }}"
- name: Deploy via DevOps Cockpit
  run: |
    curl -fsS -X POST "{{ base_url }}/pipelines/{{ pipeline.id }}/trigger" \
      -H "X-Webhook-Token: ${{ '{{' }} secrets.COCKPIT_WEBHOOK_TOKEN {{ '}}' }}"

Add the token above as a repo secret named COCKPIT_WEBHOOK_TOKEN (Settings → Secrets and variables → Actions) rather than pasting it into the workflow file.

Repo Settings → Webhooks → Add webhook:

Payload URL: {{ base_url }}/pipelines/{{ pipeline.id }}/webhook/github
Content type: application/json
Secret: {{ pipeline.webhook_token }}

Only applies to the native GitHub webhook above -- it's the one path here that fires on every push regardless of branch. The generic trigger URL doesn't need this: gate it yourself, e.g. a GitHub Actions workflow's own on: push: branches:.
